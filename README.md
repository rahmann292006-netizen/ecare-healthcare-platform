# ecare

**Your City's Trusted Healthcare Guide**

ecare is an independent healthcare directory for Raichur, Karnataka. It helps people discover hospitals, labs, specialists, and health packages. Users send appointment requests only — a request is not a confirmed booking. ecare is not an official partner of any hospital or lab.

## Hard rules

- Never invent provider data (prices, timings, doctors, ratings, accreditations).
- Unknown or unverified data must display as "Not verified" or "Contact provider".
- Every important fact must carry a source URL and verification date.
- No medical records and no AI diagnosis in the MVP.
- Patient data must never be publicly exposed.
